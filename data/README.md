# Source data

Download the IBM sample `WA_Fn-UseC_-Telco-Customer-Churn.csv` from the [dataset page on Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) and place it here under that filename. The supplied local `.xls` attachment was actually comma-separated text; rename that same file to `.csv` if you already have it.

This public portfolio does not redistribute the source data. The sample describes a fictional telecommunications company; it is not a set of actual customer records.
